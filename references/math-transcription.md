# Conservative mathematical transcription

Read formulas from the PDF page visually. Text extraction may help copy long
expressions, but the page image is the authority for superscripts, subscripts,
fractions, radicals, Greek letters, vectors, matrices, limits, sums,
integrals, scientific notation, and units.

Prefer display math for standalone equations:

```latex
$$
v^2-v_0^2=2ax
$$
```

Use inline `$...$` only for short expressions inside a sentence. Preserve
spacing and units in a readable way, but do not change a symbol's meaning.

When any glyph, exponent, sign, denominator, or subscript is uncertain:

1. transcribe only what is visually confirmed;
2. keep the uncertain source expression or a bounded crop;
3. add a `Transcription note` naming the PDF page and uncertainty;
4. revisit the original page before finalizing if the formula affects meaning.

Do not use context to manufacture a likely equation. A correct-looking LaTeX
formula that was guessed is worse than an explicitly unresolved expression.
